# TickTalk

Метроном для занятий на барабанах, которым можно управлять голосом на русском.
Руки заняты палочками, поэтому говорите: «плюс два», «восемьдесят шесть»,
«давай триолями», «стоп». Метроном выполнит команду и подтвердит её коротким сигналом.

**[Скачать TickTalk для Mac](https://github.com/luchininaolya-cyber/TickTalk/releases/latest/download/TickTalk.dmg)**

## Что нужно

- Mac с macOS 14 Sonoma или новее.
- Подходят Mac на чипах Apple (M1, M2, M3, M4…) и Mac на Intel.
- Микрофон: встроенный, наушники или AirPods.

Какая у вас версия macOS, можно посмотреть в меню  → «Об этом Mac».

## Как установить

1. Откройте скачанный файл `TickTalk.dmg`.
2. Перетащите TickTalk в папку «Программы».
3. Откройте TickTalk из «Программ». macOS сообщит, что не может проверить приложение.
   Нажмите «Готово».
4. Откройте «Системные настройки» → «Конфиденциальность и безопасность».
   Прокрутите вниз до блока «Безопасность» и нажмите «Всё равно открыть» рядом
   со строкой про TickTalk. Введите пароль от Mac.

Шаги 3–4 нужны один раз. Дальше TickTalk открывается как обычное приложение.

### Почему macOS предупреждает

TickTalk сделан для себя и друзей, он не из App Store и не зарегистрирован у Apple
(для этого нужна платная подписка разработчика). Поэтому macOS не может проверить,
кто его сделал, и просит подтвердить запуск вручную.

Если вы привыкли к Терминалу, вместо шагов 3–4 можно выполнить одну команду:

```bash
xattr -dr com.apple.quarantine /Applications/TickTalk.app
```

## Разрешения

При первом нажатии на кнопку микрофона macOS попросит два разрешения:

- **Микрофон** — чтобы слышать команды.
- **Распознавание речи** — чтобы превращать слова в команды.

Нажмите «Разрешить» в обоих окнах. Если доступ случайно запрещён, в TickTalk появится кнопка
«Открыть настройки». Она откроет нужный раздел, там включите TickTalk.

Речь распознаёт сама macOS: по возможности прямо на Mac, иначе через серверы Apple.
Сам TickTalk записи никуда не отправляет.
Совет: громкость входа микрофона в «Системных настройках» → «Звук» → «Вход»
лучше держать на 60–80 %.

## Что можно сказать

| Что сказать | Что произойдёт |
|---|---|
| «плюс два», «медленнее на 4», «быстрее» | темп ± |
| «86», «темп 120» | установить темп |
| «триоли», «восьмые», «шестнадцатые» | деление доли |
| «три четверти», «шесть восьмых» | размер такта |
| «старт», «поехали» / «стоп», «хватит» | старт и стоп |
| «громче», «громкость 50 процентов» | громкость |
| «дерево», «ковбелл», «давай бочку» | звук клика |
| «разгон по 2 каждые 4 такта», «выключи разгон» | постепенное ускорение темпа |

Можно сказать несколько команд сразу: «давай 90 и триолями».
Команда выполняется, когда вы замолкаете примерно на полсекунды.

## Обновления

Само приложение не обновляется. Чтобы поставить новую версию, скачайте `TickTalk.dmg`
по ссылке выше и перетащите TickTalk в «Программы» с заменой.
Настройки и разрешения сохранятся.

Узнавать о новых версиях можно через GitHub: кнопка **Watch** вверху страницы →
**Custom** → **Releases**. Нужен аккаунт на GitHub.

## Нет Mac?

Есть веб-версия, она открывается в браузере на телефоне, планшете и компьютере:
https://ticktalk-flame.vercel.app

Голос в браузере распознаётся хуже, чем в приложении для Mac, но всё остальное работает так же.
